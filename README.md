# MethodsLab_Ro-o_CaitleenSilmarien.
Description

This Java program demonstrates the use of methods, parameters, return values, loops, arrays, and conditional statements. 
It performs basic mathematical operations and solves several number-related problems using separate methods.

Methods Used
PrintMultiplication(int, int) – Multiplies two numbers and returns the result.
PrintAddition(int, int) – Adds two numbers and returns the result.
PrintSubtraction(int, int) – Subtracts the second number from the first.
PrintDivision(double, double) – Divides two numbers and returns a decimal result.
PrintFactorial(int) – Calculates and returns the factorial of a number.
PrintSumArray(int[]) – Calculates the sum of the elements in an array.
PrintPrime(int) – Checks whether a number is prime and returns true or false.
PrintMaxInArray(int[]) – Finds and returns the largest number in an array.
PrintGCD(int, int) – Calculates the greatest common divisor of two numbers.
PrintLCM(int, int) – Calculates the least common multiple of two numbers.
